# Powder test

User story: Käyttäjänä pystyn liikuttamaan kameraa pelissä.

Hyväksymiskriteerit: Jauhoa voi lisätä ja vähentää. Jauheen muutos näkyy pelissä.

Ominaisuus on testattu manuaalisesti staging-palvelimella. Testissä todettiin, että jauhe näkyy pelissä,
sitä voi lisätä ja vähentää lusikalla ja mikrolusikalla, sekä sitä voi lisätä nesteeseen, jolloin seoksen pH-arvo muuttuu.
Jauhe näkyy tällä hetkellä kokoajan lusikassa, ja se ei näy nesteessä, mutta nämä ominaisuudet tehdään tulevaisuudessa.
